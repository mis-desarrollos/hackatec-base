# HackaTec — ESP32 Starter Kit

Repositorio base oficial del kit ESP32 utilizado durante HackaTec.

Este repositorio proporciona ejemplos mínimos funcionales y documentación para que los equipos puedan validar rápidamente el hardware y comenzar a desarrollar su solución sin perder tiempo en configuración inicial.

---

# Hardware incluido

Cada equipo recibe:

- ESP32 con display LCD TFT 1.14” integrado
- Conectividad WiFi + Bluetooth Low Energy (BLE)
- Cable USB
- Acceso a este repositorio base

---

# Características del dispositivo

- Microcontrolador ESP32 dual-core
- WiFi 2.4GHz
- Bluetooth BLE
- Pantalla TFT ST7789 integrada
- Resolución 135x240
- Programación mediante USB-C
- Compatible con Arduino IDE y MicroPython

---

# Objetivo del repositorio

El propósito de este repositorio es:

- Validar funcionamiento del hardware
- Reducir tiempo de setup
- Proveer ejemplos base funcionales
- Facilitar pruebas de conectividad
- Permitir que los equipos se enfoquen en la solución del reto
